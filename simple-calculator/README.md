# Simple Calculator

A simple calculator program written in C.

## Description
This program displays a menu with four calculator options:
- Add
- Subtract
- Multiply
- Divide

The user can select 0 to quit the program.

## Compilation
Compile the program using:

`gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator`

## Usage
Run the program using:

`./calculator`ии
